# Heritage Immersia

This project uses Vite to resolve Three.js, Spark, dynamic imports, and files from `public/`.
VS Code Live Server is not compatible with the 3D viewer.

## Run locally

```powershell
npm install
npm run dev
```

Open the URL printed by Vite, normally:

```text
http://127.0.0.1:5173/
```

Direct Hongsheng Temple route:

```text
http://127.0.0.1:5173/?site=hongsheng-temple
```
